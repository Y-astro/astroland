# Illogical Impulse Configuration Snapshot

This directory contains a static snapshot of the illogical-impulse configuration files captured from `/home/astro/.config/illogical-impulse/`.

## Files
- `config.json`: Live shell and widget configurations snapshot.
- `wallpaper_order.json`: Configured order and metadata for wallpapers.
- `widget_extensions.json`: Extension mapping for custom user widgets.

## Usage Note
These files are an exported point-in-time snapshot for tracking and recovery. They are not active runtime configurations and do not perform any installation or deployment actions automatically.
To restore manually, copy the files back to `~/.config/illogical-impulse/`.
